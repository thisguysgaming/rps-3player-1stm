
# Advanced 3-Player Rock Paper Scissors Predictor (LSTM)

This Streamlit app uses an LSTM neural network to predict the next winner (Red, Blue, or Green) 
in a 3-player RPS game based on past round data.

## Features
- Learns sequences using RNN (LSTM)
- Predicts the next winner
- Displays prediction probabilities

## How to Run
```bash
streamlit run rps_3player_predictor_lstm.py
```
